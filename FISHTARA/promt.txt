## 4. INTEGRASI INSTAGRAM

Integrasikan website dengan akun Instagram resmi:

https://www.instagram.com/fishtara.official/

Ketentuan:
1. Tombol Instagram harus mengarah ke akun resmi.
2. Buat section khusus Instagram pada homepage.
3. Siapkan komponen untuk menampilkan postingan Instagram terbaru.
4. Jika memungkinkan, gunakan Instagram oEmbed atau Instagram Graph API sesuai ketentuan resmi Meta.
5. Jangan menggunakan scraping Instagram atau metode ilegal untuk mengambil postingan.
6. Jika membutuhkan access token, App ID, atau konfigurasi Meta, siapkan environment variable dan dokumentasikan cara mengaturnya.
7. Jika API belum tersedia, tampilkan galeri foto yang dapat dikelola melalui website dan tombol menuju Instagram.
8. Jangan menampilkan data Instagram palsu seolah-olah merupakan postingan asli.
